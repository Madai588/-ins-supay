# Manual breve de usuario

## Administrador

- **Clientes e instrumentos:** crear el cliente, registrar el instrumento y usar “Ver QR” para imprimir la etiqueta.
- **Reparaciones:** registrar diagnóstico, cambiar el estado y agregar repuestos. El stock se descuenta automáticamente.
- **Inventario:** crear proveedores y materiales; registrar entradas/salidas. Las filas amarillas indican stock mínimo.
- **Ventas:** seleccionar cliente, instrumento, fecha y total mayor que cero.
- **Cobros:** seleccionar una reparación existente, monto y fecha.
- **Reportes:** elegir periodo, revisar ingresos, stock y reparaciones; imprimir o exportar CSV.
- **Respaldos:** generar, descargar, restaurar o eliminar copias desde el menú Respaldos. Confirmar siempre antes de restaurar.

## Maestro Luthier

- Consultar clientes, instrumentos y materiales.
- Registrar diagnósticos y cambiar estados de reparación.
- Agregar repuestos usados; el sistema descuenta el stock y registra la salida.
- Escanear el QR o escribir el código manualmente para consultar el historial.
- No tiene acceso a ventas, cobros, reportes financieros ni gestión de inventario.
